# Project 1 — Boolean Logic

Implemented the 15 logic chips specified in Nand2Tetris Project 1.

## Concepts
- Boolean logic
- NAND as a universal gate
- Hierarchical chip design
- Multiplexers and demultiplexers
- 16-bit buses
- Multi-way MUX/DMUX

## Implementation
All chips were implemented using the Nand2Tetris HDL and tested using the Hardware Simulator.
